
# ot-security-notes

Notas sobre seguridad en entornos industriales (OT/ICS): patrones de fallo, modelos de amenaza y controles.

Escribo desde la experiencia en mantenimiento industrial y la formación en ciberseguridad. El enfoque es defensivo: describir el patrón, el riesgo y el control, sin pasos de explotación.
